# Agentic Harness

A hands-on course in building an AI agent harness, one small step at a time. It uses JavaScript on Node with a local [Ollama](https://ollama.com).

Each lesson folder is a complete, runnable copy of the code at that point, with a short lesson note. See [COURSE.md](COURSE.md) for the full plan.
